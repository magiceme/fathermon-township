# Beta validation and known limits

The release is an incremental development beta of the supplied v0.5 game. The final browser-run outcome is recorded in `test-summary.json`; the tests are reproducible with `npm test`.

## Verified workflows

- Original Chapters 1–3, including authentic resource gathering, cottage placement, invitations, friendship, restoration, crafting, decorating, marketplace and neighborhood milestones.
- All ten original playable characters; actual high/low detail 3D meshes, animation state, WebGL operation and original-art mode.
- Three slots; migration from v0.3, v0.4 and v0.5; malformed backup rejection; JSON export/import and continued progress.
- Biome resources and seeds, three-watered-stage crops, harvest/cooking costs, underwater pearls, lesson gates, swimming, diving, gliding and landing.
- All thirteen indoor furniture recipes; extra material costs; 3D room picking; moving, rotation and finishes; wing furniture persistence; real furniture use including sleeping, food consumption, lighting and daily plant care.
- Handmade outdoor furniture, meaningful resident projects, daily meal gatherings, homes and attached modules, material-preserving undo/redo.
- Thirty additional original guest concepts, unique models and portraits, original/expanded hotel daily limits, conversations, gifts, move-ins and saved homes; 32 plots across eight neighborhoods.
- Sixty-two collectibles and their valid habitat/hour/weather/season windows, rare weighted selection, net/pole construction, exact specimen consumption, museum donations.
- Service construction gates, physical expansion, upgrade costs and undo, park meals, pizza ingredients, daily purchases, research, errands and greenhouse improvements.
- Daily quest and achievement claims, calendar boundaries and birthday validation, one-time festival rewards, watered growth timers and daily reset; four seasons, forecasts, rain watering and seasonal yield.
- Built bridge crossing; touch movement and camera sticks with release; Chromebook keyboard/Shift-drag camera/native typing; emulated 390×844, 844×390 and 1366×768 layouts; context loss, absent WebGL and isometric fallback.
- A network-disabled inline rendering of the complete standalone HTML, with no external asset requests. Original artwork integrity is recorded in `art-integrity.json`.

Some subsystem tests use a documented post-story fixture to isolate costs, gates and claims. The separate chapter test completes the original requirements through production actions; subsystem fixtures are not evidence of a second manual story playthrough.

## Current limitations

- This is a beta. Physical Android and Chromebook devices, Safari/Firefox, prolonged memory/battery use and a freshly restored cloud task have not been validated. Browser layouts and touch/keyboard input were emulated in Chromium.
- The managed Chromium installation blocks navigation to local `file://` URLs. The same self-contained HTML was exercised through HTTP and as an inline document with networking disabled. Serving the file gives predictable origin-based storage.
- Saves, birthday preferences, diary text and progress stay in browser storage. Export JSON before moving to another browser, device, or origin. Each guest is an original township concept; the user's ten Fathermon drawings remain the canonical designs.
- Character movement uses procedural mesh deformation. The exported GLB files contain the ten original-design static meshes; the game applies their animation at runtime. Extra guest meshes are generated by source code.
- Diving renders a riverbed scene at the same world coordinates. Flight uses a bounded altitude and a crafted glider. Ridge lessons open trails; terrain heights use lightweight decorative geometry.
- Undo/redo covers design edits in the current session. Importing/loading clears edit history; permanent decisions such as move-ins and learned lessons also clear it. Saved town progress and materials remain.
- Crops need two or three watered stages. One stage completes after four real minutes or advancing to the next town day; each new stage needs watering again. Rain can water plots. The original rest-to-next-day action remains available.
- Town seasons last 28 game days each. Birthdays and annual holidays use the separate real-date calendar, defaulting to America/New_York and editable in the game.
- Chapter 4 is reserved for later development. The existing three chapters remain the story progression; the new town systems add optional activities and original guest concepts.

## Environment and publication

The current cloud instance has a verified frozen-lockfile install, build tools, Chromium and local startup workflow. The user reviews/saves those settings and publishes the environment through the product; a saved draft is not publication.
